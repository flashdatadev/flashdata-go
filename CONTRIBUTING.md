# Contributing

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs)

Use Go 1.25+. Run `go test ./...`, `go vet ./...`, and `gofmt -w` on changed Go files. Add meaningful regression coverage for behavior changes. Tests and examples must remain runnable against offline fixtures without real keys, trials or cloud writes. Keep secret values out of fixtures and error output.

Source inputs, optional parameter structs, provider payload hints and wire response types are generated by `python scripts/generate.py` from checked-in contracts and sanitized examples. Run gofmt on the generated output. Do not change a contract snapshot without checking the authoritative backend route/schema and retaining Python/TypeScript parity for the shared developer operations. Browser session operations are outside the API-key SDK surface.

Every guide links to FlashData and the official API docs. Keep English as README.md, the 简体中文 link at the top, and matching runnable examples in README.zh-CN.md. Publication and deployment require a separate explicit request.
